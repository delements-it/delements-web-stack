# Shopify Executor Tools

## Local Programs
- `$BSI_ROOT/local_programs/shopify_codex_bridge` - Primary execution path
- `$BSI_ROOT/local_programs/shopify_brain_builder` - Brain maintenance

## MCP Tools Available
All Shopify MCP tools via `bsi-shopify-mcp` agent.

## Common Operations
- `shopify__get-products` - List products
- `shopify__get-product-by-id` - Get product details
- `shopify__create-product` - Create new product
- `shopify__update-product` - Update product
- `shopify__get-orders` - List orders

## Shopify CLI
- `shopify theme list` - List themes
- `shopify theme dev` - Start dev server
- `shopify theme push` - Push theme changes

## Notes
- Access token must be valid
- Store domain must be correct
- Theme publish requires approval
