# Figma Executor Tools

## MCP Tools Available
All 23 Figma MCP tools via `bsi-figma-mcp` agent.

## Common Operations
- `getPages` - List all pages in file
- `createFrame` - Create new frame
- `createComponent` - Create reusable component
- `setFillColor` - Update node colors
- `exportNode` - Export as PNG/SVG/PDF

## Notes
- Plugin must be running in Figma Desktop
- File must be open for operations to work
