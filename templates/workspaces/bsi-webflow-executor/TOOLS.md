# Webflow Executor Tools

## MCP Tools Available
All Webflow MCP tools via `bsi-webflow-mcp` agent.

## Common Operations
- `webflow__sites_list` - List all sites
- `webflow__pages_list` - List pages in site
- `webflow__collections_items_create_item` - Create CMS item
- `webflow__collections_items_update_items` - Update items
- `webflow__pages_update_page_settings` - Update SEO

## Notes
- OAuth token must be valid
- Site must exist before operations
