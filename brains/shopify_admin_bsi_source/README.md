# Shopify Admin BSI Source Corpus

Corpus nguon nay duoc dung de build `Shopify Admin BSI Brain` bang local program `rr-obsidian-brain`.

## Muc tieu

- Giu cac note nguon cho governance, rules, playbooks, va execution contract
- Khong dung truc tiep package read-only lam dau vao builder
- Cho phep sinh manifest va rebuild vault lap lai theo mot quy trinh on dinh

## Cau truc

- `source_files/`: note markdown nguon cho Shopify brain
- `converted_md/`: duoc tao boi pipeline local de mo phong output cua lop Markdown conversion
- `manifests/`: `directory_mapping_current.json`, `md_files_current.json`, va report nhe

## Nguyen tac

- Source corpus co the duoc Brain Owner cap nhat co chu dich
- Execution chats khong duoc sua source corpus nay trong luong van hanh thong thuong
