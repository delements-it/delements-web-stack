# Brain Owner and Executor Paths

## Brain Owner path

Brain Owner workflow duoc dung cho:

- cap nhat source corpus
- cap nhat registry
- rebuild vault
- sua builder va bridge khi can thay doi he thong

Cong cu thuoc owner path:

- `shopify_brain_builder`
- source corpus
- built vault maintenance

## Executor path

Executor chats chi duoc dung:

- `shopify_codex_bridge`
- `shopify-dev-mcp`
- Shopify CLI trong pham vi duoc phep

Execution chats khong duoc su dung `shopify_brain_builder` de thay doi he thong.
