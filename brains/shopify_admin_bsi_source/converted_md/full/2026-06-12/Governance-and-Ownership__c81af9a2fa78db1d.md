# Governance and Ownership

## Ownership

- `Business Systems Integration` la owner cua shared Shopify brain
- `Admin BSI` la authority cho governance, implementation-safe recommendation, va integration ownership

## Shopify la participating system

Shopify trong context nay duoc xem la mot he thong tham gia vao:

- commerce workflows
- order and payment flows
- inventory and WMS sync
- CRM va automation integrations

No khong tu dong tro thanh mot project governance doc lap chi vi co local MCP hoac local program.

## Default analysis frame

Moi task Shopify nen co:

1. systems involved
2. entity or transaction involved
3. source of truth
4. write boundary
5. sync direction
6. failure and reconciliation path
7. operational owner
