# Bug Proposal Workflow

Execution chats duoc de xuat bug va toi uu he thong, nhung khong sua truc tiep brain.

## Khi nao tao proposal

- local program route sai
- rule thieu hoac mau thuan
- registry thieu thong tin can thiet
- MCP path hoac plugin environment co loi
- auth flow hoac prompt injection can toi uu

## Proposal can co

- van de
- anh huong
- cach tai hien
- de xuat sua
- muc do uu tien

## Rule

- proposal la output phu
- khong thay the governance change
- chi Brain Owner moi duoc chap nhan va cap nhat source corpus
