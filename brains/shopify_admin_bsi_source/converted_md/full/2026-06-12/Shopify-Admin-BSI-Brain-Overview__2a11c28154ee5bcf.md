# Shopify Admin BSI Brain Overview

`Shopify Admin BSI Brain` la bo nao dung chung cho cac task Shopify thuoc pham vi `Business Systems Integration`.

## Muc tieu

- giu governance va safety rule thong nhat
- lam entrypoint chung cho execution chats dung Shopify MCP va Shopify CLI
- dat Shopify trong khung system integration cua BSI, khong tach thanh ownership doc lap

## Cach dung

- execution chats doc brain nay thong qua local program
- docs va schema route qua `shopify-dev-mcp`
- live store actions route qua `Shopify CLI`
- neu thay can cai tien he thong, execution chats chi tao proposal
