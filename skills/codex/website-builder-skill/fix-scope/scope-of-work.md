# Scope Of Work

Created: 2026-05-23

## Objective

Prepare the local program so it can safely coordinate Qwen local + OpenClaw + Codex/Webflow MCP using Lean/Kanban flow.

## In Scope

- local program analysis and audit flow
- Qwen/OpenClaw handoff contract
- Codex/Webflow MCP escalation rules
- Kanban WIP and Definition of Ready/Done
- command schema/allowlist planning
- artifact freshness and secret redaction planning
- Webflow mutation safeguards

## Out Of Scope For This Phase

- installing OpenClaw
- running Qwen local
- changing Webflow production site
- adding npm dependencies
- implementing full Lighthouse/axe/Playwright integrations

## Deliverables

1. `process/end-to-end-workflow-audit.md`
2. `process/lean-kanban-operating-model.md`
3. `fix-scope/fix-backlog-kanban.md`
4. `fix-scope/scope-of-work.md`
5. Updated `SKILL.md` with Lean/Kanban process references.
6. Synced package skill for local program and Codex.

## Definition Of Done

- local program can list the skill and attachments
- workflow audit files exist in the root skill folder
- package skill includes matching process/fix-scope files
- zip archive includes the updated skill set
- no credentials are introduced
