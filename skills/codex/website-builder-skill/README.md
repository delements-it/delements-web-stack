# Website Builder Skill

Created: 2026-05-23

This folder turns the GitHub research into a compact skill set for Webflow/local website automation.

## Files

- `SKILL.md` - main skill entrypoint for Codex, Qwen local, or OpenClaw.
- `references/github-project-analysis.md` - analyzed and filtered GitHub projects.
- `references/local-program-skill-map.md` - how each tool maps to local program functions.
- `rules/ui-ux-responsive-mobile.md` - UI, UX, responsive, and mobile-friendly rules.
- `rules/seo-google-ai-optimization.md` - SEO and Google AI-search readiness rules.
- `rules/webflow-spline-guardrails.md` - Webflow, Finsweet, and Spline integration guardrails.
- `rules/escalation-routing.md` - local vs Qwen vs Codex ownership.
- `process/end-to-end-workflow-audit.md` - full local/Qwen/OpenClaw/Codex process audit.
- `process/lean-kanban-operating-model.md` - Lean/Kanban workflow policies.
- `fix-scope/fix-backlog-kanban.md` - prioritized fix cards and acceptance criteria.
- `fix-scope/scope-of-work.md` - scope, deliverables, and done criteria.

## Intended Runtime

Use this skill with:

1. Local program for deterministic analysis and execution.
2. Qwen local/OpenClaw for bounded reasoning and patch generation.
3. Codex/Webflow MCP only for complex Designer-native or high-risk production tasks.
