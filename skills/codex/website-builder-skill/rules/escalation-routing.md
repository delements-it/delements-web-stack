# Escalation Routing

## Local Program Owns

- static HTML analysis
- live URL fetch and basic DOM analysis
- Chrome screenshot audit
- Lighthouse, axe, responsive matrix when installed
- SEO/indexability/schema validation
- image optimization
- repair packet generation
- Webflow CMS sync with dry-run
- custom code apply with dry-run
- publish execution only after approval

## Qwen Local/OpenClaw Owns

- prioritize findings
- write CSS/JS patches
- create CMS schemas and import mappings
- rewrite title/meta/FAQ/content drafts
- propose responsive repair plan
- create command JSON for local program

## Codex/Webflow MCP Owns

- Designer-native canvas work
- complex Webflow IX2 interactions
- component/class architecture changes
- tricky browser debugging after repeated Qwen failure
- production or domain-sensitive work

## Escalation Triggers

Escalate from local to Qwen when:

- local findings require content judgment
- schema/content/patch must be generated
- multiple medium/high issues require prioritization

Escalate from Qwen to Codex when:

- two Qwen repair loops fail
- Webflow Designer/MCP is required
- generated patch is risky or broad
- production publish/domain/credential/payment risk appears
